Top Countries by Sales Volume & Revenue

SELECT invoice.billing_country,
       SUM(invoice_line.quantity) AS total_units,
       ROUND(SUM(invoice_line.quantity * invoice_line.unit_price)::numeric, 2) AS total_revenue
FROM invoice
JOIN invoice_line ON invoice.invoice_id = invoice_line.invoice_id
GROUP BY invoice.billing_country
ORDER BY total_revenue DESC;
Top 10 Countries by Total Revenue ($)

Finding: The USA ($1,040.49; 1,051 units) leads globally, generating nearly double the revenue of second-place Canada ($535.59), followed by Brazil ($427.68), France ($389.07), and Germany ($334.62).

2. Music Concert Planning (Marketing Dept.)

To support a promotional Rock music concert, queries were written to select host cities with the highest invoice totals, extract Rock listener contacts, and rank the top 10 Rock artists by catalog size.

Top 3 Revenue-Generating Cities

SELECT invoice.billing_city,
       SUM(invoice_line.quantity * invoice_line.unit_price) AS total_revenue
FROM invoice
JOIN invoice_line ON invoice.invoice_id = invoice_line.invoice_id
GROUP BY invoice.billing_city
ORDER BY total_revenue DESC
LIMIT 3;

Recommended Concert Cities: Prague ($273.24), Mountain View ($169.29), and London ($166.32).

Rock Music Listener Mailing List & Top 10 Rock Artists

-- Alphabetical Rock listeners (59 contacts returned)
SELECT DISTINCT email, first_name, last_name
FROM customer
JOIN invoice ON customer.customer_id = invoice.customer_id
JOIN invoice_line ON invoice_line.invoice_id = invoice.invoice_id
WHERE track_id IN (
    SELECT track_id FROM track
    JOIN genre ON genre.genre_id = track.genre_id
    WHERE genre.name LIKE 'Rock'
)
ORDER BY email;

-- Top 10 Rock artists by unique track count
SELECT artist.name, COUNT(DISTINCT track.track_id) AS tracks
FROM artist
JOIN album ON album.artist_id = artist.artist_id
JOIN track ON track.album_id = album.album_id
WHERE track.genre_id = '1'
GROUP BY artist.name
ORDER BY tracks DESC
LIMIT 10;

3. Advanced Insights with CTEs

Using multi-table joins and Common Table Expressions (CTEs), we analyzed artist-level spend, the most popular genre per country, and the single highest-spending customer in every market.

Top-Spending Customer per Country (CTE)

WITH top_spenders_per_country AS (
    SELECT c.country, c.customer_id, SUM(i.total) AS total_spent
    FROM customer AS c
    JOIN invoice AS i ON c.customer_id = i.customer_id
    GROUP BY c.country, c.customer_id
)
SELECT tspc.country,
       c.first_name || ' ' || c.last_name AS customer_name,
       ROUND(tspc.total_spent::numeric, 2) AS total_spent
FROM top_spenders_per_country AS tspc
JOIN customer AS c ON tspc.customer_id = c.customer_id
GROUP BY tspc.country, customer_name, tspc.total_spent
HAVING tspc.total_spent = (
    SELECT MAX(total_spent)
    FROM top_spenders_per_country
    WHERE tspc.country = top_spenders_per_country.country
);

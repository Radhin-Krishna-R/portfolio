Customer Complaint Analysis

An end-to-end machine learning pipeline built to clean financial complaint records, uncover dispute drivers through exploratory analysis, and predict whether a consumer will dispute a company's resolution.

View Code & Dataset on GitHub →

Introduction & Objective

Completed during the Edureka Data Science and Machine Learning internship, this project covers the full machine learning lifecycle: data cleaning, exploratory data analysis (EDA), feature engineering, Principal Component Analysis (PCA), and comparative classification modeling.

When customers are dissatisfied with financial products—such as mortgages, credit cards, or debt collection—they file complaints. The primary objective is to predict the binary target variable Consumer disputed? (Yes/No) using Python (Pandas, Matplotlib, Seaborn, and Scikit-Learn) so institutions can proactively flag high-risk cases.

Data Cleaning & Feature Engineering

  • Missing Value Pruning: Audited data types across train and test sets and dropped columns with more than 25% missing values.
  • Temporal Feature Extraction: Extracted Day, Month, and Year from Date received, and derived Week_Received.
  • Resolution Duration: Computed Days held (difference between date sent and date received) and clipped negative durations to zero.
  • Imputation & Cleanup: Imputed missing State values using the mode and dropped non-predictive identifiers (Complaint ID, ZIP code, and raw date columns).

Model Building & Evaluation

After splitting the dataset into dependent and independent variables and reducing dimensionality via PCA, seven classification algorithms were trained and benchmarked on both test and validation accuracy: Logistic Regression, Decision Tree, Random Forest, AdaBoost, Gradient Boosting, K-Neighbors, and XGBoost.

Test and Validation Accuracies of Different Models

Conclusion

Based on combined test and validation accuracy scores, Logistic Regression (~78.6% test / ~78.6% validation) alongside ensemble methods—Gradient Boosting, AdaBoost, and XGBoost—delivered the strongest and most consistent generalization performance, outperforming standalone Decision Trees and K-Neighbors.

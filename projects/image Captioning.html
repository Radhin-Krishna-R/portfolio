Offline Image Captioning & Object Detection

Created for my final-year undergraduate capstone project, this is a compact, self-reliant computer vision system engineered for sub-200ms offline inference—laying the groundwork for assistive technologies, bionic vision, and neuro-prosthetic devices.

Problem & Motivation

Developed as my final-year undergraduate project, this work tackles a core limitation of modern visual AI: most state-of-the-art image captioning systems depend on cloud-hosted Large Language Models (LLMs) and heavy transformer pipelines. In assistive technologies—such as wearable vision aids, bionic eyes, and neuro-prosthetics—cloud dependency is a critical flaw. Network latency disrupts real-time spatial awareness, connectivity is not guaranteed, and streaming live visual feeds raises serious privacy concerns.

To bridge this gap, I built a lightweight, fully offline vision-to-language pipeline capable of real-time object detection and natural language captioning on edge hardware without external APIs or internet access.

Two-Phase Architecture

Phase 1 — Real-Time Object Detection & Classification: Uses a fine-tuned lightweight YOLOv11n model (2.6M parameters, 6.5 GFLOPS) trained on the MS COCO dataset (80+ object classes). Input frames are resized to 640×640, normalized, and filtered via Non-Maximum Suppression (NMS) to output bounding boxes, class labels, and confidence scores at ~30 FPS.

Phase 2 — Image Captioning (Encoder-Decoder with Attention): Trained on the Flickr8k dataset (8,000 images with 5 human-written captions each). A pre-trained CNN backbone (EfficientNet / InceptionV3) extracts dense spatial feature maps from 299×299 images. These representations are passed through an attention-guided decoder (LSTM with Bahdanau attention and a custom Transformer Encoder-Decoder with causal masking) to generate captions autoregressively from a 10,000-word vocabulary using sparse categorical cross-entropy loss and teacher forcing.

Edge & Web Deployment

Live Webcam Pipeline: Built with OpenCV (cv2.VideoCapture), capturing live frames, running local inference without cloud calls, and overlaying real-time bounding boxes and confidence labels under 50ms per frame.

Interactive Streamlit Web Apps: Two local browser interfaces were deployed using Streamlit—a Video Object Detection app (supporting MP4/AVI/MOV uploads, confidence threshold sliders, COCO class filtering, and downloadable annotated video) and an Image Captioner app for instant offline scene descriptions.

Tech Stack & Datasets

  • Frameworks & Libraries: Python 3.9, TensorFlow 2.12, Keras, Ultralytics YOLOv11, OpenCV 4.7, Streamlit 1.25, NumPy, Matplotlib.
  • Datasets: MS COCO (330,000+ images, 80+ classes) for detection; Flickr8k (8,000 images, 40,000 captions) for sequence generation.
